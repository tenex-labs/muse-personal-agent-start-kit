# Optional: give Muse a physical home

Once you have a useful setup, try JJ’s [pocket agent build](https://github.com/JJenglert1/esp32-muse-agent). It covers supported hardware, pairing, and an optional voice add-on. This is a separate hobby project, not a requirement for the starter kit.

Check the guide’s current board support and costs before buying. Keep device tokens and API keys private. Do not upload firmware containing credentials or your completed configuration to this repository.
