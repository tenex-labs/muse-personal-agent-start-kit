# Muse in plain English

## Agent

An assistant that can use tools to carry out tasks, beyond answering questions.

## Main chat

Your general conversation with Muse.

## Side chat

A separate thread for a job. It organizes work; it is not an isolated account or memory vault.

## Memory / memory.md

Saved facts and preferences. Locate the actual memory file in your account before editing.

## SOUL / soul.md

Instructions for tone and working style. The exact file name can vary.

## Feed

Content and ideas to explore based on your interests.

## Activity

A record of work Muse performed, useful for checking actions and errors.

## Artifact

An output you can revisit: a page, document, checklist, or tracker.

## Goal

An ongoing outcome you want help pursuing, such as finding a car.

## Routine / scheduled task

A repeated action at an agreed time or cadence. Verify it exists after asking.

## Heartbeat

A periodic check for ongoing work. It is not proof a specific task ran, and you do not need to edit it to start.

## Connector

An authorized connection to another service, such as a calendar. Availability varies.

## Permission

The access or action you approve in the app. A prompt is not a replacement for permission controls.

## Cloud vs. local

Cloud work runs away from your device. Local computer actions depend on that device being available.
