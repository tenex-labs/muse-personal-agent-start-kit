# Habits that make Muse more useful

Adapted from JJ’s personal cheat sheet, with private details removed.

1. Give each ongoing job its own side chat.
2. State the result first, then the constraints.
3. Correct in one line: “Under this budget. No exceptions.”
4. Ask it to show what it saved to memory.
5. Verify live prices, dates, and availability before recommending.
6. Use the quietest cadence that still helps.
7. Alert once per new qualifying result.
8. Keep scheduled sources available in the cloud when possible.
9. Keep booking, sending, and buying under your control.
10. Start with one job you care about and improve it before adding more.

For voice: use Muse’s voice input when available. If your phone supports an Action Button or shortcut, check whether Muse offers a supported action. Do not assume JJ’s device setup exists on yours.
